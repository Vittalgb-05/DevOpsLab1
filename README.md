# 🚀 DevOpsLab1

This repository demonstrates hands-on practice of Git commands and core DevOps concepts through structured lab exercises.

---

## 📌 Objective

- 🧠 Practice essential Git commands  
- 🔄 Understand version control workflow  
- ⚙️ Learn fundamental DevOps concepts  
- 📁 Manage repositories efficiently  

---

## 🛠 Tools & Technologies Used

- 🐙 Git  
- 🌐 GitHub  
- 💻 Command Line Interface (CLI)  
- 🖥 Linux / Windows Terminal  

---

## 📂 Topics Covered

- 📌 Git repository initialization  
- ➕ Add, commit, and push operations  
- 🌿 Branch creation and management  
- 🔀 Branch merging  
- 🔄 Pull and fetch operations  
- ⚠️ Handling merge conflicts  
- 📥 Repository cloning  

---

## 🔄 Workflow Demonstrated

1️⃣ Initialize local repository  
2️⃣ Add and commit files  
3️⃣ Create custom branches  
4️⃣ Merge branches into `main`  
5️⃣ Resolve merge conflicts  
6️⃣ Push changes to remote repository  

---

## 📘 Conclusion

This lab enhanced practical understanding of Git operations and DevOps fundamentals.  
It improved hands-on experience with branching strategies, merging workflows, and remote repository management.
