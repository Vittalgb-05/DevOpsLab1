# 🚀 DevOpsLab

This repository contains basic Git and DevOps command execution practice.

## 📌 Purpose

- 🧠 Practice Git commands
- 🔄 Understand version control workflow
- ⚙️ Learn basic DevOps concepts
- 📁 Perform repository management operations

## 🛠 Tools Used

- 🐙 Git
- 🌐 GitHub
- 💻 Command Line Interface (CLI)
- 🖥 Linux / Windows Terminal

## 📂 Topics Covered

- 📌 Git initialization
- ➕ Add, commit, and push operations
- 🌿 Branch creation and merging
- 🔄 Pull and fetch commands
- ⚠️ Handling merge conflicts
- 📥 Repository cloning

## 📘 Conclusion

This lab helped in understanding the practical implementation of Git commands and core DevOps fundamentals. It improved hands-on knowledge of version control systems and repository management.
